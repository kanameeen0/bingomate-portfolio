# BingoMate Portfolio

## プロジェクト概要

BingoMateは、オンラインビンゴ大会の運営を支援するWebアプリ。

主催者は大会を作成し、参加者はQRコードから参加。
抽選結果やビンゴ状況をリアルタイムで共有し、景品管理まで行えるシステム。
---

## 開発体制

- 開発形態：チーム開発
- 担当：フロントエンド
- 開発人数：2人

## 工夫した点

### プレイヤー一覧画面

参加者数が増えても管理しやすいように、

- 検索
- 並び替え
- フィルタ

機能を実装しました。

主催者が必要な参加者を素早く見つけられることを意識して設計しました。

### API連携

バックエンド担当者とAPI仕様を確認しながら開発を進めました。

TypeScriptで型定義を行い、フロントエンドとバックエンド間のデータ受け渡しミスを減らしました。
